1. It found "Gmail" in the text
2. There was a checkmark (✓) somewhere nearby in the context
3. It didn't properly check that the app was marked as NOT USED

STEP 2: Fixed HTML Extraction Logic
------------------------------------
Updated generate_html.py to use stricter pattern matching:

BEFORE:
```python
if app in company_text:
    if '✓' in context or '**' + app + '**' in company_text:
        apps.append(app)
```

AFTER:
```python
# Look for bold app name with checkmark pattern: **AppName** ✓
bold_pattern = r'\*\*' + re.escape(app) + r'\*\*\s*✓'
if re.search(bold_pattern, company_text):
    # Check for negative indicators
    is_not_used = any(x in context for x in
                     ['NOT USED', 'NOT CONFIRMED', 'NO EVIDENCE',
                      '❌', '✗', 'NOT FOR'])
    if not is_not_used:
        apps.append(app)
```

This ensures:
- Only extracts apps with explicit **AppName** ✓ pattern
- Checks for negative indicators (NOT USED, ✗, etc.)
- Doesn't extract apps from casual mentions
